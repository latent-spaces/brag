# Security

`/brag` reads a project in order to make a video the author may post in public. A run must not carry secrets, credentials, or personal data into the plan, the video, or the share copy. The skip lists in the skills are the current rule for that.

## Reporting

Please don't open a public issue that contains a secret, a customer record, or an unreleased project file. Email the author listed in `plugin.json` instead, and describe the problem without pasting the secret itself.

If a rendered brag included something that should have stayed private, say which step kept it (inspect, plan, or the render) so the skill text can be tightened.

# /brag-cleanup

Clean up intermediate artifacts after generating a brag launch video.

`/brag` produces several intermediate build and planning artifacts during video production:
- Storyboard and planning rubric (`brag-plan.md`)
- Composition handoff brief (`composition-brief.md`)
- Full Hyperframes composition source and asset copies (`composition/`)
- Temporary frame extraction samples or test images

Once the final video (`brag.mp4`), cover image (`brag.jpg`), and share text (`share-copy.txt`) are produced, the intermediate files take up significant disk space and clutter the workspace. `/brag-cleanup` safely purges these non-essential files while guarding against premature deletion.

---

## Retained Deliverables (Never Deleted)

| Deliverable | Description |
|---|---|
| `brag.mp4` | Final rendered video file with audio, SFX, and baked poster at frame 0 |
| `brag.jpg` | High-resolution settled poster / cover image for thumbnail upload |
| `share-copy.txt` | Primary social post caption |
| `share-copy-variants.md` | Platform-specific caption variants (Twitter, LinkedIn, Discord) |

---

## Intermediate Files Purged

| Target | Description |
|---|---|
| `composition/` | Hyperframes source HTML, duplicated audio tracks, SFX files, and runtime cache |
| `brag-plan.md` | Internal planning document and storyboard rubric |
| `composition-brief.md` | Technical design and audio cue specifications |
| `*.poster.mp4`, `test*.jpg`, `frame_*.jpg` | Temporary FFmpeg pass outputs or frame diagnostic dumps |

---

## Safety Guardrails (Before Purging)

1. **Verify `brag.mp4` exists**:
   Never delete the composition source if `brag.mp4` does not exist or has zero bytes. Abort immediately with an error unless `--force` is specified.

2. **Verify `brag.jpg` exists**:
   If `brag.jpg` is missing but `brag.mp4` exists, automatically extract the poster frame before deleting other files:
   ```bash
   ffmpeg -y -ss 2.0 -i <target-dir>/brag.mp4 -frames:v 1 -q:v 2 <target-dir>/brag.jpg
   ```

---

## CLI & Script Usage

The cleanup script is located in `<skill-dir>/scripts/cleanup.sh`.

```bash
# Run in the project containing brag-output/
bash <skill-dir>/scripts/cleanup.sh

# Preview files that would be removed without deleting
bash <skill-dir>/scripts/cleanup.sh --dry-run

# Target a specific timestamped directory
bash <skill-dir>/scripts/cleanup.sh --dir ./brag-output-2026-09-20-143022/

# Keep composition files, only remove planning documents
bash <skill-dir>/scripts/cleanup.sh --keep-composition

# Force cleanup even if video is missing (caution!)
bash <skill-dir>/scripts/cleanup.sh --force
```

---

## Agent Workflow

When invoked with `/brag-cleanup`:

1. **Locate Target Directory**:
   Look for `brag-output/` or timestamped `brag-output-*/` directories in the current workspace. If multiple exist and no flag is given, ask the user or clean the latest modified one.

2. **Run Safety Audit**:
   - Check that `<output-dir>/brag.mp4` exists and is > 10KB.
   - If missing, stop and inform the user that the video has not been rendered yet.
   - Ensure `<output-dir>/brag.jpg` exists (extract if missing).

3. **Delete Intermediate Files**:
   ```bash
   rm -rf "<output-dir>/composition"
   rm -f "<output-dir>/brag-plan.md"
   rm -f "<output-dir>/composition-brief.md"
   rm -f "<output-dir>"/*.poster.mp4 "<output-dir>"/test*.jpg "<output-dir>"/frame_*.jpg
   ```

4. **Summarize**:
   Print the retained files, their file sizes, and the reclaimed disk space.

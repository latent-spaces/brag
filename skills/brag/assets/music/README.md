## Regenerating the presets

`analyze_music_cues.py` writes both files. It keeps at most 64 strong cues. From `skills/brag/scripts`, with the project's Python dependencies installed:

```bash
uv run analyze_music_cues.py ../assets/music/<track>.mp3 \
  --output-json ../assets/music/cues/<track>.music-cues.json \
  --output-md ../assets/music/cues/<track>.music-cues.md
```

Replace `<track>` with the mp3 filename without `.mp3`. The default planning window is the first 25 seconds, which is what the markdown summary is for. The JSON keeps the full track.
